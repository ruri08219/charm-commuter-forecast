One line of weather forecast for a city that doesn't exist — Drizzlewick, where it rains at 11°, the 8:15 bus runs ten minutes late, and the bus-shelter roof leaks only over the timetable, never over the queue. Built for a bored commuter at a rainy bus stop: a real forecast's rhythm, bent just enough to make them smile.

## Run it

```sh
python3 main.py
```

The program writes the single-line forecast to `/output/entry.txt` (UTF-8, 132 characters, one line plus a trailing newline).
